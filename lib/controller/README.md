This repository implements a simple and customizable memory controller framework for implementing the PIM module of any memory controller. This framework is ***not*** intended for memory mode use. It handles both switching in and out of memory mode and PIM commands but *not* DRAM commands. This is due to the inseparability of DRAMsim3 from its informal memory controller implementation.
